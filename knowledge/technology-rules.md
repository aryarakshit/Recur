# Technology Rules & Guidelines
*Updated: 2026-09-19*

## Allowed Languages & Frameworks
- You are free to use any programming language (Python, TypeScript, Rust, Go, Java, etc.) and any application framework.
- Hardware projects, mobile apps, web applications, CLI tools, and browser extensions are all welcome.

## APIs, Cloud & AI Tools
- Third-party APIs (such as Gemini, OpenAI, Groq, Anthropic, Twilio, Supabase, Firebase) are completely permissible.
- You are responsible for provisioning and securing your own API keys. Never commit API keys or private credentials to public GitHub repositories.
- Code generation assistants (Cursor, GitHub Copilot, ChatGPT) may be used, but participants must understand and be able to explain their code during judging.

## Boilerplate Code
- Standard boilerplates, project starter templates (e.g. `create-react-app`, Next.js starters, FastAPI boilerplates) are allowed if disclosed in your README.
